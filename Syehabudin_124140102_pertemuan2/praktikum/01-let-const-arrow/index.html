Let, const & arrow functions

Bandingkan scope variabel, perubahan objek const, dan beberapa bentuk arrow function.

Scope variabel dan const

Nilai var di luar blok ikut berubah. Variabel let di dalam dan di luar blok tetap berbeda.

Properti objek const boleh diubah. Reassign dan akses sebelum deklarasi dicoba dalam try/catch agar error dapat ditampilkan.



Fungsi reguler dan arrow function
Hasil mencakup implicit return, tanpa parameter, satu parameter, dan pengembalian objek.
