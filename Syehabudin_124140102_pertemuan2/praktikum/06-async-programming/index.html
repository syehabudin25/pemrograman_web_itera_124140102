Async programming

Gabungkan dua sumber data dengan retry, loading, error handling, pagination, dan pencarian debounce.

Sumber data dan pencarian

Pencarian berjalan setelah berhenti mengetik selama 350 ms.

Mode lokal memakai dua file JSON. Mode online menggabungkan endpoint users dan posts dari JSONPlaceholder.

Proses async

  • Dua sumber dimuat bersamaan melalui Promise.all().
  • Kegagalan dicoba ulang maksimal 3 kali, dengan jeda 250 ms lalu 500 ms.
  • Setiap permintaan memiliki batas waktu 4 detik.
  • Error ditangani oleh withErrorBoundary() dan ditampilkan di halaman.
  • Hasil async ditampilkan sebanyak 5 postingan per halaman.
  • Pencarian baru membatalkan permintaan lama agar hasil tidak tertukar.
